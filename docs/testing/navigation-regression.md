# 统一左侧导航验收

2026-10-03 完成导航改造并更新本地 Docker 前端，访问地址为 http://127.0.0.1:3010。本次恢复原合规系统的侧栏样式和页面容器规则，保留现有业务页面；原五角色回归问题仍按原清单跟踪。

## 布局依据与实现

参考仓库外归档中的 `compliance-evaluation/frontend_backup/src/layouts/DashboardLayout.tsx`，以及案件系统的 `LegalLayout`、`BusinessLayout`、`VendorLayout`。归档位置通过本机 `.local/archive-index.json` 查询，不作为构建依赖。

| 区域 | 实现与原布局规则 |
| --- | --- |
| 侧栏 | slate-900 背景，展开 256px、收起 80px；菜单图标、字号及蓝色选中态沿用合规样式 |
| 一级菜单 | 案件管理、合规检查、合规考核、系统管理；浅一档背景、稍粗字重和折叠箭头区分层级 |
| 顶栏 | 白色背景、高度 64px；展示平台名、用户及退出入口 |
| 合规页面 | 内容直接进入可滚动主区域，不再额外套统一 p-6；h-full 工作台获得完整剩余高度 |
| 总部案件与公共系统管理 | 外层保留 p-6；业务组件的表格、表单、弹窗和内部间距不改动 |
| 分支及部门案件 | 恢复 max-w-5xl 居中，p-4 / md:p-8 与底部留白 |
| 律师门户 | 恢复 max-w-7xl 外层和原白色带边框的内容面板 |
| 窄屏 | 1024px 以下侧栏转为左侧模态抽屉，支持关闭按钮、Escape 和选中菜单后关闭 |

组件分工为 `App → AppShell → SidebarNavigation / Header / PageFrame`。菜单定义、权限过滤和详情页归属在 `navigation.ts`；原兼容路由与业务权限判断保留在 `App.tsx`。

系统管理标签改为以 URL 查询参数为准，保证页内标签、左侧菜单、刷新与浏览器历史一致。除此以外，未修改业务页面组件或全局 CSS。
