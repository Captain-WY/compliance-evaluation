- **管理员**：身份及系统管理读取正常；字典新增修改和跨模块读回正常。角色/菜单/任务模板多条写路径500，维护链未通过。

- **分支**：检查签收、材料退回重提、确认及申辩可执行；待办状态和裁决展示异常。考核举证、撤回、补证及成绩确认可执行。日常台账保存提示成功，后端重启后实际消失。
- **业务部门**：线索上报和案件协作任务通过，非成员/财务越权拒绝有效。浏览器协查页因旧接口404一直加载；检查附件存在越权下载。
- **外聘律师**：已分派案件门户可见、未分派案件被拒。但已分派详情授权、任务负责人映射、提交事务及前端办理入口均有问题，律师完整办理链未通过。
