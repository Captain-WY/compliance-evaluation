## 当前安排

- 系统管理：优先复核 REG-009 公共写入事务，覆盖管理员操作和律师提交；随后 REG-018。
- 案件管理：从 REG-011/012 的律师授权与身份映射开始，协调 REG-009 依赖；后续安排 REG-010/013/019。
- 合规检查：优先 REG-003 附件权限，随后 REG-007/008 正常闭环，再处理 REG-015/016/017；REG-021 先明确业务决定。
- 考核相关 REG-001/002/004/005/006/014/020 暂缓，用户恢复考核范围后重新排序；公共改动直接影响时做必要兼容检查。

以上为候选顺序；每批由模块工作说明收敛目标，不把所有问题一次纳入同一批。关闭问题须复验原失败场景及直接受影响行为，按风险补充角色拒绝、读回、重启或迁移验证；不能仅凭构建或 HTTP 200 关闭。
